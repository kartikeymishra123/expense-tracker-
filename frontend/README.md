# 💰 Expense Tracker

A full-stack Expense Tracker web application that helps users manage and track their daily expenses efficiently.

---

## 🚀 Live Demo

🔗 **Live:** https://cashflowly.netlify.app/

---

## 🚀 Features

* 📊 Add, update, and delete expenses
* 📅 Track daily spending
* 💾 Persistent storage (database/local storage)
* 📈 Clean and responsive UI
* 🔗 Full-stack integration (Frontend + Backend)

---

## 🛠️ Tech Stack

### Frontend:

* HTML
* CSS
* JavaScript (or React if used)

### Backend:

* Node.js
* Express.js

### Database:

* MongoDB (if used)
